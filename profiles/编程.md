## 定位
本库讨论软件系统如何被构造、调试、部署和维护，以及工程约束下的实现与取舍。判断看文章的主要问题是否落在代码、架构、工具链或运行机制上，而非作者身份或是否含命令。

## 收录范围
- 语言语义、编码校验、数据结构与底层机制（汇编、IO 流、YAML 规范、海明码、四元数）。
- 前后端工程实践：鉴权与权限、Cookie 安全、前端预加载、样式修复、性能优化。
- 系统机制与可靠性：消息队列选型、调度策略、版本控制模型、幂等与重试。
- AI 辅助编程的工程化：代码审查、上下文与规则文件、多工具分工、Agent 验证与 Harness 归因。
- 自托管与部署：Docker、Nginx、静态站点、评论系统、图床与服务器迁移中的工程实现。
- 开源许可证、开发工具选型与开发者技术写作中涉及实现方法的部分。

## 典型主题
鉴权方案、Cookie 安全、消息队列选型、Claude Code 与 Skills 工程化、AI 生成代码审查、Docker 自托管、Git/jj 版本控制、前端预加载、开源许可证兼容性、四元数与骨骼动画

## 边界与排除
- **数理**：若文章终点是定理、编码原理、算法模型或 Agent 机制解释，而非可运行系统问题，归数理；本库只收落到实现与排错的部分。
- **技法**：面向使用者照做的部署、换模型、接入平台、写测试流程，命令虽多但缺工程机制解释，归技法；本库收解释系统为何这样构造的文章。
- **浪潮**：判断 AI 工具能力、产业变化、内容生产影响，归浪潮；本库收具体代码质量、工具链配置与工程实现。
- **经营**：客户、定价、增长、营收、产品身份与市场验证为主，归经营；本库只留技术复用与架构边界。
- **研学**：学习方法、求职规划、能力成长与书单，归研学；本库不收单纯如何变强。
- **时评**：公共权利、平台伦理、群体处境评价，归时评；本库不收以技术事件为背景的公共批评。
- **文史**：语言词源、技术史、许可证文化史若以文化文本为对象，归文史；本库收许可证选型与开发实践。
- **人物**：以开发者生涯、命运、关键选择为主线，归人物；本库收其技术实现部分。
- **娱乐**：游戏、图形作品机制与体验，归娱乐；本库只收引擎、渲染、算法等实现问题。

## 主次判断与评分
主轴是软件构造、调试、部署或工程取舍：核心明确 0.80~1.00，主体基本符合 0.50~0.79。技术只是背景、关键词或作者身份，0.20~0.49；主体命中他库或排除项，0~0.19。两个主轴难分时保留低分进入待定，不以「作者是程序员、标题有 AI、步骤多、正文未给结论」抬高分数。
